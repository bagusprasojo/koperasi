Aturan Ketat Import Data Master:

  • Kategori & Satuan Wajib Ada: Sistem tidak membuat kategori atau satuan baru secara otomatis. Pastikan nama kategori dan kode/nama satuan sudah terdaftar di data master (dapat dilihat pada sheet "Referensi Master Data" di dalam template).
  • SKU Unik: SKU tidak boleh duplikat di dalam file Excel dan tidak boleh sudah ada di database.
  • Aturan All-or-Nothing: Jika ditemukan 1 saja baris error, tombol proses simpan akan dinonaktifkan dan seluruh data tidak bisa disimpan hingga file diperbaiki.
